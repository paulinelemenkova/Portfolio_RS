# Portfolio in Cartography and Remote Sensing

LaTeX (Beamer) source of the invited portfolio presentation **"Portfolio in
Cartography and Remote Sensing"** by Polina Lemenkova, given at the Department of
Geoinformatics, Paris Lodron University of Salzburg (PLUS), Austria, on
21 December 2023.

The 22-slide deck surveys applied work in remote sensing and geospatial data
science, with worked examples and figures.

## Contents

- `Portfolio_RS_Polina.tex` — the Beamer presentation source (theme *Szeged*).

The talk covers:

- Image processing and segmentation of Landsat 8-9 OLI/TIRS imagery; parametric classification (eCognition); colour composites; time-series land-cover dynamics
- Vegetation indices, image classification and accuracy assessment with GRASS GIS
- Programming for geospatial analysis in Python and R; conceptual workflow modelling
- Remote-sensing methods in geophysics; 3D topographic modelling and cross-sections with the GMT scripting toolset
- Statistical data modelling and a summary of related publications
